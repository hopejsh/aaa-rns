# Getting help

- **Questions, ideas, "how do I …"** → [Discussions](../../discussions). Please look there first;
  answers are indexed and help the next person.
- **Bug reports and feature requests** → [Issues](../../issues), using the templates.
- **Security problems** → do **not** open a public issue. See [SECURITY.md](SECURITY.md).

## Before you file

Include your OS, Python version, browser, and the interface language you were using
(Korean / English / Japanese) — several past defects appeared in only one language.
The browser console output is usually decisive; open it with F12 → Console.

## What is not supported

This project does not provide validation documentation, regulated-environment
qualification (IQ/OQ/PQ), or a hosted service. See the honest-limits section of the
[README](README.md).
