  AI 에이전트 연구노트 자동화 시스템 (AAA-RNS) — 설치 안내
══════════════════════════════════════════════════════════════

■ 설치

  1. 이 압축파일을 원하는 위치에 풉니다.
     → 그것으로 설치가 끝입니다. 별도 설치 프로그램이 없습니다.
       (서버·DB·인터넷이 필요 없는 완전 독립형 소프트웨어입니다)

■ 실행 — 더블클릭 한 번이면 첫 화면이 자동으로 열립니다

  ● Mac      : start_mac.command  더블클릭
               ※ 처음 한 번 "확인되지 않은 개발자" 경고가 뜨면
                 파일을 우클릭 → [열기] → [열기] 를 선택하십시오.

  ● Windows  : start_windows.bat  더블클릭
               ※ 처음 한 번 SmartScreen 경고가 뜨면
                 [추가 정보] → [실행] 을 선택하십시오.
               ※ Python 이 없어도 됩니다 — 자동으로 PowerShell
                 서버로 실행됩니다.

  실행하면 검은 창(서버)이 뜨고, Chrome/Edge 브라우저가 자동으로
  열리면서 첫 화면(온보딩)이 나타납니다.

  ⚠ 검은 창을 닫으면 시스템이 종료됩니다. 작업 중에는 열어 두십시오.
  ⚠ 공유폴더 연결(팀 협업) 기능은 Chrome 또는 Edge 에서만 동작합니다.

■ 첫 화면에서 할 일

  ① 연구 문서 업로드  — 연구개발계획서·제안서·일정표·지표표 등
                         (PDF · DOCX · XLSX · HWPX · CSV · TXT)
     ※ 체험해 보려면 sample_docs 폴더의 샘플 문서를 올려 보십시오.
  ② 심층 분석         — 과제 구조 자동 추출
  ③ 추출 결과 확인    — 각 항목 확인·수정
  ④ 시스템 생성       — 귀사 전용 연구노트 자동화 환경 완성

■ 문제 해결

  · 브라우저가 자동으로 열리지 않으면 주소창에 직접 입력:
      http://localhost:8777
  · "포트를 열 수 없습니다" 오류: 이미 실행 중인 창이 있는지 확인
  · 화면이 이상하면 브라우저에서 강력 새로고침: Ctrl+Shift+R (Mac: Cmd+Shift+R)
