■ インストール

  1. この圧縮ファイルを好きな場所に展開します。
     → それでインストールは完了です。インストーラーはありません。
       完全に自己完結しており、サーバーもデータベースもインター
       ネット接続も登録キーも必要ありません。

■ 起動 — ダブルクリック一回で最初の画面が自動的に開きます

  ● Mac      : start_mac.command をダブルクリック
               ※ 初回に「開発元が未確認」の警告が出たら、ファイルを
                 右クリック →［開く］→［開く］を選んでください。

  ● Windows  : start_windows.bat をダブルクリック
               ※ 初回に SmartScreen の警告が出たら
                 ［詳細情報］→［実行］を選んでください。
               ※ Python は不要です — 自動的に PowerShell サーバーで
                 起動します。

  黒いウィンドウ（サーバー）が現れ、Chrome または Edge が最初の画面を
  開きます。

  ⚠ 黒いウィンドウを閉じるとシステムが終了します。作業中は開いたまま
    にしてください。
  ⚠ 共有フォルダモード（チーム協業）は Chrome または Edge でのみ
    動作します。
  ⚠ サーバーウィンドウの表示は、選んだ画面言語にかかわらず英語です —
    ターミナルのフォントが日本語を正しく描画できない場合があり、
    文字化けよりは英語がよいと判断しました。

■ 最初の画面ですること

  ① 研究文書のアップロード — 研究開発計画書・提案書・日程表・指標表
                              （PDF・DOCX・XLSX・HWPX・CSV・TXT）
     ※ まず試すなら sample_docs フォルダのサンプルをアップロード。
  ② 詳細分析              — 課題構造を自動抽出
  ③ 抽出結果の確認        — 各項目を確認・修正
  ④ システムの生成        — 自社専用の研究ノート環境が完成

  画面の言語は初回起動時にブラウザの言語に従い、右上でいつでも変更
  できます（한국어 / English / 日本語）。

■ 文書（別途提供）

  この圧縮ファイルには実行に必要なファイルのみが入っています。
  必要な文書は GitHub リポジトリから個別に入手してください。

    ・ docs/ja/installation-guide.pdf  実際の画面キャプチャ付きの
                                       インストール・利用ガイド
    ・ docs/ja/user-manual.md          日常利用のリファレンス
    ・ docs/ja/verification-report.md  シミュレーション検証結果
    ・ docs/ja/training-deck.pdf       チームへの導入説明用スライド

  （한국어・English 版は docs/ko/・docs/en/ に同じファイル名で
    あります。インストールと初回利用はこのファイルだけで足ります。）

■ トラブルシューティング

  ・ ブラウザが自動で開かない場合はアドレス欄に直接入力：
       http://localhost:8777
  ・「ポートを開けません」: 既に起動中のウィンドウがないか確認
  ・ 表示が崩れる場合はブラウザで強制再読み込み：
       Ctrl+Shift+R （Mac: Cmd+Shift+R）
